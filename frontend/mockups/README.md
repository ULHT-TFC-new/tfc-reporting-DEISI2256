# Mockups estáticos (DEISI2256)

Ecrãs principais da plataforma de TFC em HTML e CSS estáticos, pedidos pelo orientador na Reunião 8 (18/11). Os dados são fictícios (baseados nos dados de demonstração do backend) e os botões não gravam nada.

**Como abrir:** abrir `index.html` no browser. Não é preciso servidor nem instalar nada.

| Perfil | Ecrãs |
|---|---|
| Aluno | Lista de propostas com filtros; página do TFC com a candidatura individual ou em grupo; candidaturas por ordem de preferência e grupo; confirmação pelo colega |
| Docente | Os meus TFC com o número de candidatos; selecionar candidato; submeter proposta |
| Coordenação | Todos os TFC; selecionar, confirmar e publicar a atribuição (botão à parte do de selecionar) |

**CSS:** `css/mockups.css` começa com as variáveis de formatação (tipo e tamanho de letra, cores, espaços). O botão «Tema escuro» só redefine as variáveis de cor. Todas as combinações de cor têm contraste de pelo menos 4,5:1, nos dois temas, e as páginas foram verificadas com o axe-core (regras WCAG 2 A e AA) sem erros.

Os ecrãs das avaliações (por docente e de controlo) ficam para uma fase seguinte.
